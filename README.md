# 角色主题绑定（character-theme-binder）

为特定角色绑定【背景 / UI 主题】并可保存图片/照片信息，在切换到该角色时自动应用背景与主题。

## 功能
- 在扩展设置页新增“角色主题绑定”入口按钮（固定名称）。
- 弹窗内：
  - 一键绑定当前酒馆选择器中的【背景/主题】到“当前聊天角色”；
  - 图片（主图）来源：使用当前背景 或 本地上传（带预览与清除）；
  - 照片：本地上传（带预览与清除）。
- 切换聊天角色时自动应用绑定的背景与主题。

## 文件结构
- `manifest.json`：扩展清单（SillyTavern 扩展格式）
- `index.html`：扩展设置页 UI（含“角色主题绑定”入口按钮与弹窗结构）
- `index.js`：扩展逻辑（绑定/解绑、弹窗交互、图片/照片保存、本地上传、自动应用）

## 从 GitHub URL 安装（SillyTavern）
1. 将本仓库发布为公开仓库（Public）。
2. 复制本扩展目录的 RAW ZIP 地址，或直接使用仓库的 ZIP 下载链接；也可复制单文件 RAW 链接（建议用 ZIP）。
3. 在 SillyTavern 中打开：设置 → 扩展 → “从 URL 安装”（Install from URL）。
4. 粘贴上述 URL 并确认安装。

注意：
- 该扩展为 SillyTavern 扩展，manifest 中的 `entrypoint` 指向 `index.js`，`files` 指向扩展所需文件。
- 本扩展使用 SillyTavern 的 `extension_settings` 持久化数据，无需 `chrome.storage`。
- 本地上传的图片/照片会以 base64 保存在设置中，为避免数据体积过大，默认限制 2MB 以内。

## 使用方法
1. 在酒馆里先选择好你想要的背景和 UI 主题；
2. 打开需要绑定的角色聊天；
3. 打开 设置 → 扩展 → 找到“角色主题绑定器（Theme Binder）”模块，点击“角色主题绑定”按钮打开弹窗；
4. 点击“绑定当前背景/主题”完成绑定；
5. 在图片设置/照片设置中选择“使用当前背景”或上传图片/照片，确认预览后点击“保存”；
6. 需要解除时点击“解除绑定”。

## 构建/发布建议
- 无需构建步骤（纯前端资源）。
- 提交到 GitHub 后，建议创建 Release 并附上完整扩展 ZIP，便于在 SillyTavern 的“从 URL 安装”中使用 Release 资产直链。
- 若使用 RAW 链接安装，请确保链接可直接下载对应文件/ZIP（GitHub RAW/CDN）。

## 常见问题
- 看不到入口按钮？请在设置 → 扩展页中找到“角色主题绑定器（Theme Binder）”模块，入口按钮位于模块内。
- 绑定后未自动切换？请确认你在聊天界面切换到了绑定的角色；并确保背景/主题选择器元素（#bg_select / #theme_select）存在且可用。
